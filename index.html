How it works

Hutsix organizes automation into profiles made of bindings. Each binding pairs a trigger with an action: a trigger detects an event (global hotkey, mouse input, pixel color, image match, OCR text, or a trained AI image model), and an action plays a keyboard or mouse sequence. When a profile is active, a watchdog engine continuously evaluates bindings and executes actions only when the configured conditions are satisfied.

  1. Install a Hutsix release and launch the app.
  2. Create or import a profile.
  3. Add a trigger (hotkey, mouse, pixel color, image match, OCR text, or AI image).
  4. Attach an action sequence (keyboard or mouse playback).
  5. Activate the profile and validate behavior with the Action Monitor and per-binding diagnostics.

System requirements

  • OS: Windows 10 or Windows 11, 64-bit
  • Administrator rights: required to install
  • Internet: required for the first license activation, with an offline grace period afterwards

The rest depends on which triggers you use. The core automation path is far lighter than the AI path — the heavy numbers some pages quote for this category are for model training, not for running profiles.

  • Hotkeys, macros, pixel and template triggers: 2 CPU cores (4 recommended), 8 GB RAM, no GPU. These paths run on the CPU by design.
  • OCR text and AI image triggers: 4+ CPU cores and 16 GB RAM recommended. A CUDA-capable NVIDIA GPU with 4–8 GB VRAM makes them substantially faster; without one they still work, checking about twice a second.
  • Training your own detection model: 16–32 GB RAM, CUDA GPU with 8 GB+ VRAM, and 10 GB+ free space for datasets and model output.
  • Storage: the installer downloads about 3.4 GB — almost all of it the bundled AI and CUDA runtime — so plan on 10 GB free, plus room for datasets if you train models.
  • Display: multi-monitor and HDR displays are supported.

Hutsix runs both CPU and GPU execution paths. CUDA acceleration applies to supported AI and vision workloads, and every feature falls back to the CPU when a GPU is unavailable or too slow to be worth using.
