How it works

Hutsix organizes automation into profiles made of bindings. Each binding pairs a trigger with an action: a trigger detects an event (global hotkey, pixel color, image match, or OCR text), and an action plays a keyboard or mouse sequence. When a profile is active, a watchdog engine continuously evaluates bindings and executes actions only when the configured conditions are satisfied.

  1. Install a Hutsix release and launch the app.
  2. Create or import a profile.
  3. Add a trigger (hotkey, pixel, image, or OCR text).
  4. Attach an action sequence (keyboard or mouse playback).
  5. Activate the profile and validate behavior with the Action Monitor and per-binding diagnostics.

System requirements

  • OS: Windows 10/11 (64-bit)
  • CPU: 6+ logical cores
  • RAM: 16 GB for core automation; 32 GB recommended for AI modules (YOLOX/OCR/training)
  • GPU: NVIDIA with CUDA recommended for best YOLOX/OCR performance (8 GB+ VRAM preferred); CPU fallback supported
  • Storage: SSD with 10 GB+ free space (more for datasets and models)

Hutsix supports both CPU and GPU execution paths. CUDA-enabled acceleration applies to supported AI and vision workloads, and features fall back to CPU when GPU acceleration is unavailable.
